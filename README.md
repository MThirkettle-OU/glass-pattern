# Glass Pattern Experiment

This repository contains a simple HTML/JavaScript experiment for visualizing Glass patterns, commonly used in studies of visual perception and global form processing.

## Features

- Displays dot pairs (dipoles) arranged in different configurations:
  - Circular
  - Radial
  - Spiral
- Instructions and current pattern type are shown above the canvas.
- Use keyboard controls to switch between pattern types.

## How to Run

1. Download or clone this repository.
2. Open `glass_pattern_experiment.html` in any modern web browser.
3. Follow the on-screen instructions.

## Controls

- **→ Arrow Key**: Switch to the next pattern type.
- **← Arrow Key**: Switch to the previous pattern type.
